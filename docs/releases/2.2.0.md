# TABANG 2.2.0 — Separate Name Fields Update

TABANG is the Transfusion Access, Blood Availability and Network Guidance research prototype for Digos City, Davao del Sur. This release splits account names into first name, middle name and last name across the data model, the sign-up flow, profile editing and the Supabase blueprint.

## Changes

- **Account names**
  - Accounts now store `firstName`, an optional `middleName` and `lastName` separately. The full name is composed only for display, search and audit records.
  - The middle name is optional; leaving it blank stores `null` rather than an empty string.
  - Initials are built from the first and last name only, so a missing middle name no longer produces a stray placeholder character.
  - The demo seed users are split into first and last names, preserving compound given names and suffixes.

- **Sign-up and account creation**
  - The registration review now shows First name, Middle name and Last name as separate rows.
  - First and last name are required; the middle name field is labelled optional.
  - Chapter staff creating a walk-in account collect the same three fields.
  - Name validation applies per field, and the alias check still compares against the composed full name.

- **Profile and admin surfaces**
  - Profile editing uses three name fields and rewrites the display name from them.
  - Audit entries and account summaries use the same split-name labels.
  - Help text and onboarding copy describe the new fields.

- **Backend blueprint**
  - The Supabase `profiles` table now has `first_name`, `middle_name` and `last_name` columns plus a generated `full_name`.
  - The signup trigger and the `update_own_profile` RPC accept and validate the separate fields.
  - The backend guide and starter schema comments match the new shape.

## Upgrade note

Existing rows that only have a full name must be split before the generated `full_name` column is used. The app stores names separately from this release onward; the schema is still a starter blueprint, not an applied migration.
